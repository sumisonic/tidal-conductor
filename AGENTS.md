# Working on tidal-conductor

Notes for whoever works on this code, the author's coding agents included. Read [docs/design.md](docs/design.md) (why things
are the way they are) and [docs/protocol.md](docs/protocol.md) (the OSC contract) before
changing behavior; [docs/wiring.md](docs/wiring.md) explains how the pieces are used together.

## Conventions

- **English everywhere**: code, comments, prompts, logs, documents, manifest examples.
- **Functional TypeScript.** Effect for effects and concurrency, ts-pattern for matching. `for`,
  `while`, `let` and `Math.random` are rejected by `pnpm lint`; use `map`/`filter`/`reduce`,
  recursion, `const`, and `runSeeded` from `src/rand.ts`. Disable a rule only with a stated
  reason, where mutable state is genuinely required.
- **New logic goes into the pure layer** (`state.ts`, `scheduler.ts`, `pll.ts`, `render.ts`, the
  Brains' pure parts) with unit tests. Sockets, timers and files live in `conductor.ts`,
  `run.ts` and the scripts.
- **No host-specific concepts.** No players, songs, scenes, hardware sequencers, Max/MSP bridges
  or anything else tied to one particular rig. The manifest is the only configuration unit and
  the channel is the only namespace.
- **Prompt constants define the training distribution.** `SYSTEM_PROMPT`,
  `LOCAL_EXTRA_RULES` and the veto/mark block format are what the training recipe builds its
  data from, so any model trained with them depends on them. Changing them is a behavior change
  for the `local` Brain: say so in the CHANGELOG.
- **Protocol and snippets move together.** A change to any OSC address, argument or key name
  updates `docs/protocol.md`, `integration/`, `e2e/` and the CHANGELOG in the same commit.
- **Dependencies are exact-pinned.** Install with `pnpm install --frozen-lockfile`. The tested
  Node and pnpm versions are pinned in three places that must agree: `mise.toml`,
  `packageManager` in `package.json`, and `.github/workflows/ci.yml`; the `engines` field
  states the minimum and moves with them.
- **Files GHCi loads stay pure ASCII** (`integration/tidal/Conductor.tidal`, `haskell/AiPatSpec.tidal`,
  the NDJSON fixtures). Under a C locale GHCi's `:script` stops silently at the first non-ASCII
  byte; `test/ascii-guard.test.ts` enforces this.
- Commit messages: `type: summary` (`feat`, `fix`, `docs`, `build`, `refactor`, `test`, `chore`).

## Checks

Run before every commit:

```sh
pnpm check           # eslint + tsc
pnpm knip            # unused files, exports, dependencies
pnpm format:check    # prettier (pnpm format to fix)
pnpm test            # vitest
```

When the renderer, the schemas, the generators, the pool or the Brains changed:

```sh
pnpm verify:patterns # ~2,500 rendered patterns through the real parseBP (needs GHC + tidal; nix develop provides it)
```

When `integration/tidal/Conductor.tidal` or the golden fixtures changed:

```sh
pnpm verify:aipat    # the aiPat specification in GHCi
nix flake check      # the same, plus the golden parseBP fixtures, as CI runs them
```

When the clock, scheduler, deadman or SC snippet changed, run the headless end-to-end harness by
hand (it needs SuperCollider and a Tidal-capable GHC on this machine; on Linux set `SCLANG`):

```sh
NIX_FLAKE=. e2e/run.sh
```

## Do not commit

`sessions/`, `ghci/`, `training/data/`, `training/adapters/`, `training/fused/`, `.env` (all
gitignored). The JSON Schemas under `schema/` (`manifest.schema.json`,
`phrase-plan-v0.schema.json`, `phrase-plan-v1.schema.json`) are generated by `pnpm emit-schema`
and **are** committed; regenerate them when `src/schema.ts` or `src/conductor/manifest.ts`
changes.

## Layout

```
src/conductor/      the Conductor: run.ts (entry), conductor.ts (wiring), state, scheduler, pll,
                    brain/ (index = the chain, pool, offline, api, hybrid, local, types), manifest,
                    vetoMemory, preflight
src/                render.ts (plan → mini-notation), schema.ts (plan schemas), generators/, rand.ts, osc.ts
src/training/       dataset sampling for the training recipe
scripts/            pnpm entry points (case emission, api smoke, pool/feedback tools, dataset build)
test/               vitest
haskell/            ParseBPCheck.hs (fixed runner), AiPatSpec.tidal, fixtures/, shell wrappers
integration/        tidal/Conductor.tidal, supercollider/conductor.scd
e2e/                headless end-to-end harness
manifests/ plans/   example manifests, the curated pool
training/           the local-Brain recipe (README, Colab notebook)
docs/               design, protocol, wiring
```
